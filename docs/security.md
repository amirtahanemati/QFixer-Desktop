# مستندات امنیتی QFixer Desktop

## ۱. مدل امنیت مبتنی بر اصل حداقل دسترسی
- **مجوزهای Tauri 2:** تمام دسترسی‌ها به فایل‌های محلی کاربر بر مبنای دیالوگ‌های سیستمی فایل و قابلیت `core:default` محدود شده است.
- **ایزوله‌سازی Worker:** پروسه پایتون به صورت Child Process با دسترسی محدود به متغیرهای محیطی و فایل‌های ورودی/خروجی اجرا می‌شود.

## ۲. ایمنی مسیرها و جلوگیری از نفوذ
- مسیرهای ارسال‌شده برای خواندن یا نوشتن فایل از فیلتر Canonicalize و بررسی وجود در پوشه مجاز پروژه عبور داده می‌شوند تا از باگ‌های Path Traversal (`../`) جلوگیری گردد.
- فرانت‌اند به هیچ رابطی برای اجرای شل و کدهای دلخواه دسترسی ندارد.
