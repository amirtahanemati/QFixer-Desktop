# استراتژی آزمون و تضمین کیفیت QFixer Desktop

## ۱. سطوح آزمون
- **آزمون‌های واحد فرانت‌اند (Vitest):** آزمون منطق استورهای Zustand، اعتبارسنجی فرم‌ها با Zod، هوک‌های نمایش تصویر و بارگذاری ترجمه‌های fa-IR و en-US.
- **آزمون‌های واحد هسته Rust (Cargo Test):** آزمون سریالایز و دیسریالایز پروتکل IPC، نظارت بر چرخه فرآیند و مدیریت کش.
- **آزمون‌های الگوریتم‌های پردازش تصویر (Pytest):** آزمون پایداری فیلترها، عملکرد ماسک‌های حفاظتی، عدم تغییر ابعاد تصویر و عدم محو شدن خطوط متنی با تصاویر ارزیابی استاندارد (Synthetic Ground Truth).

## ۲. معیارهای کیفی
- هیچ تستی به صورت نمایشی یا بدون Assert اجرا نمی‌شود.
- تصاویر آزمایشی با مشخصات معین نویز، سایه و متن در پوشه `tests/fixtures` قرار می‌گیرند.
